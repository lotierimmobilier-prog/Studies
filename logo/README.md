# Logo « Capendu en bref »

Mot-symbole : « Capendu » en gras vert-bleu profond, « en bref » en léger lie-de-vin, point final lie-de-vin.
Police : Fredoka (texte transformé en tracés, aucune installation nécessaire). Icône : pastille ronde lie-de-vin avec un « c » blanc.

| Fichier | Usage |
|---|---|
| `logo.svg / .png` | Logo sans marge (en-tête du site, intégration dans une page) |
| `logo-avec-marge.svg / .png` | Logo avec marge (documents, signature, impression) |
| `logo-fond-fonce.svg / .png` | Sur fond vert foncé (`#12403e`) ou photo sombre |
| `icone.svg / .png` | Pastille « c » : icône d'onglet (`../favicon.svg` en est une copie), petits formats |
| `avatar-reseaux.svg / .png` | Photo de profil ronde (réseaux sociaux, Brevo) |

Couleurs : vert-bleu profond `#12403e`, lie-de-vin `#c0455e`, rose clair `#ff9db0` (sur fond foncé), aqua pâle `#f4fbfa`.

Règles : ne pas déformer, laisser une marge au moins égale à la hauteur d'un « c » autour du logo, hauteur minimale 22 px,
ne pas changer les couleurs en dehors de la palette. Le modèle d'e-mail reproduit le mot-symbole en texte (les messageries
bloquent souvent les images) ; le logo en image sert au site, aux réseaux et à l'impression.
